# Работа с репозиторием

- Оригинальные условия: `task-1/docs/SPECS.md` и `task-2/docs/SPECS.md`. Не редактировать.
- Конкурсный код находится в `submission*/`, исследовательские скрипты — в `scripts/` и `train/`.
- На локальной машине использовать conda-окружение `ml-env`; для длинных запусков — `python -u`. В Docker зависимости устанавливаются через pip.
- Журнал экспериментов: `experiments/JOURNAL.md`. Перед новым экспериментом прочитать, результаты дописывать в конец.
- README кратко описывает задачу, место и выбранные ML-решения. Не добавлять руководства, отчёты об оформлении репозитория и оговорки об авторстве результата.
